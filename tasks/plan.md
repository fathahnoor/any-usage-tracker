# Rencana implementasi

1. Buktikan pembacaan sumber dari sesi BrowserOS neo. Temukan kontrak data harian OpenRouter dan rincian paket operator.
2. Buat pembaca Codex mandiri, klien MCP lokal dan parser sumber. Uji nilai, satuan, rentang tanggal dan kegagalan.
3. Hubungkan server, cache per sumber dan UI responsif. Verifikasi dengan data akun sebenarnya.
4. Siapkan launcher, dokumentasi dan pemeriksaan akhir. Jangan mengubah server lama atau file di luar workspace.

Risiko utama: perubahan halaman pihak ketiga dan login kedaluwarsa. Kegagalan wajib terlihat tanpa mengganti angka dengan nol.
